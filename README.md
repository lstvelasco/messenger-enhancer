# Messenger Enhancer & Privacy Guard

A lightweight, feature-rich browser extension designed to enhance privacy, formatting shortcuts, UI customization, and screenshot utilities for **Facebook Messenger Web** (`https://www.messenger.com/` and `https://www.facebook.com/messages/`).

Developed by **[lstvelasco](https://velascode.com)**

---

## 🚀 Features

- 🔒 **Custom Privacy Protection:** Independent blur filters for the left sidebar and right main conversation panel with hover-to-reveal.
- 📸 **Selective Unhide (Screenshot Utility):** Hold `Ctrl + Left Click` on any chat row to permanently unblur specific messages for clean screenshots. Press `Esc` to reset all blurs.
- 🥷 **Stealth Mode:** Automatically suppresses typing indicator status and read receipts using `declarativeNetRequest`.
- ✍️ **Keyboard Formatting Shortcuts:**
  - **Text Styling:** `Ctrl + B` (*Bold*), `Ctrl + I` (_Italics_), `Ctrl + Shift + X` (~Strikethrough~), `Ctrl + Shift + M` (`Monospace`).
  - **Case Conversion:** `Alt + U` (UPPERCASE), `Alt + L` (lowercase), `Alt + T` (Title Case).
- 📐 **UI Customization:** Adjust message font size dynamically and toggle **Compact Chat Mode** to eliminate line clutter.

## 📌 Pin the Extension for Quick Access

1. Click the **Extensions icon (🧩 Puzzle piece)** on your browser toolbar.
2. Locate **Messenger Enhancer & Privacy Guard**.
3. Click the **Pin icon (📌)** to keep quick toggles accessible.

---

## 🛠️ How to Install in Your Browser

### Manual Installation (Developer / Unpacked Mode)
1. Download or clone this repository.
2. Open your browser extension management page:
   - **Google Chrome:** `chrome://extensions/`
   - **Microsoft Edge:** `edge://extensions/`
   - **Brave Browser:** `brave://extensions/`
3. Toggle on **Developer Mode** (top right / left sidebar toggle).
4. Click **Load Unpacked** and select the extension folder containing `manifest.json`.
5. Open Messenger Web and enjoy enhanced control!
